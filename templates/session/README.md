# Zero 회차 — 주제

- 유형: 모듈 구현 / 기본 원리 탐구 중 선택
- 전체 운영 주차: 미정
- Zero 회차: 미정
- 모임 날짜: 미정
- 참여자 / 기록 담당자: 미정
- 준비 시간 범위: 함께 합의

## 이번 회차의 범위

구현 회차: 개인별 만들고 싶은 모듈, 핵심 기능, 완료 기준을 적습니다. 동일한 모듈을 만들 필요는 없습니다.

원리 회차: 개인별 또는 공통 기초 영역과 핵심 질문을 적습니다. 개인별 실험 방법과 추가 탐구 깊이는 자율로 둡니다.

## 개인 기록

이름 / 개인별 주제와 접근 방법 / 기록 경로.

## 공유할 내용

- 구현: 목적 → 설계 선택과 이유 → 동작 확인 → 막힌 과정과 남은 질문.
- 원리: 질문과 예상 → 개념 설명 → 실험과 관찰 → 수정한 설명과 남은 질문.

해당 회차 유형에 맞게 준비합니다. 두 종류의 결과물을 동시에 요구하지 않습니다. 모듈 구현은 AI 없이 직접 해결한 과정을 공유합니다. 원리 탐구는 AI 활용을 허용하며, 자료와 실험으로 확인한 내용을 자신의 말로 설명합니다.

## 다음 회차 준비

다음 Zero는 반대 유형으로 진행합니다. 주제와 범위는 합의한 만큼 기록하고, 구현과 원리 주제의 연결은 선택으로 둡니다.
