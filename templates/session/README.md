# AI Zero 회차 주제

- 모임 날짜: 미정
- 회차: 미정
- 참여자: 미정
- 기록 담당자: 미정
- 개인 준비 시간 범위: 모임에서 합의

## 함께 답할 질문

이번 회차에서 함께 이해하고 싶은 질문 하나를 적습니다.

## 공통 범위

모두가 확인할 최소 범위와 이번에 다루지 않을 범위를 적습니다.

## 개인별 탐구

각자의 세부 질문·접근 방법·기록 경로를 적습니다.

## 모임 진행

개인별 공유 → 차이와 의문점 토론 → 공동 결론 → 다음 질문 합의.

## 준비할 것

질문 하나, 직접 확인한 증거 하나, 남은 질문 하나. 미완성이어도 확인한 범위와 막힌 이유를 공유합니다.
