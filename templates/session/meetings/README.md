# 세션 미팅 목록

실제 회의록은 `YYYYMMDD-kickoff.md`, `YYYYMMDD-review.md`, `YYYYMMDD-review-and-kickoff.md`, `YYYYMMDD-interim.md`처럼 보관합니다. 필요한 때 저장소의 `templates/meeting.md`를 복사해 작성합니다.

| 날짜 | 종류 | 내용 요약 | 상태 / 회의록 |
|---|---|---|---|
| 미정 | 킥오프 | 주제와 범위 선정 | 예정 |

세션 README의 미팅 목록에서 이 파일과 개별 회의록을 연결합니다. 예정 미팅에는 존재하지 않는 파일 링크를 만들지 않습니다.

이전 세션의 회고와 이 세션의 킥오프가 같은 미팅이었다면 이전 세션에 있는 원본 회의록을 링크합니다.
