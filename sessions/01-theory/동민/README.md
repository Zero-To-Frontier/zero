# 동민 — 모듈에서 프로그램 실행까지

## 탐구 목표

프로그램이 외부 코드를 어떻게 찾고, 의존성을 준비하고, 빌드하고 실행하는지 전체 흐름을 이해합니다. 아래 여섯 영역은 선정한 탐구 범위이며, 확인한 부분과 후속 탐구로 남긴 부분을 구분합니다.

## 선정한 탐구 범위

### 1. 모듈과 패키지의 구조

- 모듈과 패키지는 무엇인가?
- 라이브러리와 프레임워크는 어떻게 다른가?
- Python의 `.py`, Java의 `.class`, JAR는 각각 어떤 단위인가?

### 2. Import / Module Resolution

- Python `import`, Node.js `require`와 `import ... from`, Java `import`는 각 언어에서 무슨 역할을 하는가?
- 프로그램은 필요한 모듈이나 클래스를 어디서 찾는가?
- Python `sys.path`, Java `classpath`, Node.js `node_modules`는 어떻게 관련되는가?
- 상대 경로와 절대 경로 import는 어떻게 해석되는가?

언어별 import가 동일한 방식으로 동작한다고 가정하지 않고, 각각의 탐색·로딩 과정을 확인합니다.

### 3. 패키지 매니저와 의존성 관리

- `pip`, `npm`, `Maven`, `Gradle`은 어떤 역할을 맡는가?
- PyPI, npm registry, Maven Central 등에서 의존성을 어떻게 가져오는가?
- 내려받은 패키지는 로컬 어디에 저장되는가?
- 직접 의존성과 전이 의존성은 무엇인가?
- 버전 충돌은 왜 발생하는가?

### 4. 빌드 과정

Java를 중심으로 소스코드·의존성 준비·컴파일·`.class` 생성·JAR/WAR 패키징·실행이 어떻게 연결되는지 살펴봅니다. Maven/Gradle이 어느 단계를 관리하는지, 프로젝트와 실행 방식에 따라 흐름이 어떻게 달라지는지 확인합니다.

### 5. 런타임과 로딩

- 코드가 디스크에서 메모리로 올라와 실행되는 과정은 무엇인가?
- 정적/동적 로딩과 링킹은 각각 무엇을 뜻하는가?
- Java ClassLoader, Python `sys.modules`는 어떤 역할을 하는가?
- 공유 라이브러리, DLL, `.so`, linker와 loader는 어떻게 연결되는가?

### 6. 실행 환경과 격리

- Python `venv`, Java SDK/JDK 버전, Node.js `node_modules`는 실행 환경에 어떤 영향을 주는가?
- Docker는 실행 환경을 어떻게 다루는가?
- `PATH` 등 환경변수는 프로그램 탐색에 어떻게 사용되는가?
- 실행 파일 탐색과 언어의 모듈 탐색은 어떻게 다른가?

## 진행 제안

작은 Java 프로젝트 하나의 의존성 선언부터 빌드·실행까지 먼저 추적하고, Python과 Node.js는 차이를 이해하는 예제로 활용해도 좋습니다. 여섯 영역의 범위는 유지하되 추가로 파볼 부분은 후속 질문으로 남깁니다.

실험 후보는 의존성의 로컬 저장 위치 확인, 실행 시 클래스 탐색 경로를 바꿨을 때의 결과 관찰, 서로 다른 Python 환경에서 모듈 탐색 결과 확인 등입니다. 필요한 실험만 선택합니다.
