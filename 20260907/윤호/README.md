# 윤호 — Docker로 컨테이너를 실행하면 내부에서 무슨 일이 일어나는가?

## 탐구 목표

컨테이너의 실행과 종료를 자신의 말로 설명하고, 중지·삭제·재생성 시 어떤 일이 일어날지 예상해 직접 확인합니다.

## 핵심 질문

1. 이미지와 컨테이너는 무엇이 다른가? 각각의 역할과 관계는 무엇인가?
2. 컨테이너 안에서는 무엇이 실행되는가? 프로그램·프로세스·컨테이너는 어떻게 연결되는가?
3. 컨테이너는 무엇을 공유하고 무엇을 격리하는가? 가상머신과는 어떻게 다른가?
4. 컨테이너를 종료하거나 삭제하면 무엇이 남는가? 실행 상태와 파일·데이터 상태는 어떻게 다른가?

## 탐구 순서

| 단계 | 할 일 | 남길 내용 |
|---|---|---|
| 먼저 생각하기 | 핵심 질문에 현재 아는 만큼 답하기 | 초기 예상과 모르는 부분 |
| 개념 공부 | 공식 자료와 AI로 이해하기 | 핵심 개념과 참고 자료 |
| 직접 확인 | 작은 컨테이너로 동작 관찰하기 | 예상·실행 결과·차이 |
| 설명 정리 | 관찰 결과를 원리와 연결하기 | 수정한 설명과 남은 질문 |

## 실험 계획

먼저 볼륨이나 바인드 마운트를 따로 연결하지 않은 조건에서 확인합니다. 실제 사용한 이미지에 데이터 저장 관련 설정이 있는지도 기록합니다. 실험용 파일 경로와 생성 방법, 명령어를 남깁니다.

1. **같은 이미지로 컨테이너 두 개 실행:** 한쪽에서 만든 파일이 다른 쪽에도 보일지 예상하고 확인합니다.
2. **컨테이너 중지 후 다시 시작:** 프로그램의 실행 상태와 만든 파일이 각각 어떻게 되는지 확인합니다.
3. **컨테이너 삭제 후 같은 이미지로 새로 생성:** 이전에 만든 파일이 남는지 예상하고 확인합니다.

여유가 있으면 볼륨을 연결했을 때와 비교합니다. 사용한 운영체제, Docker 실행 환경(직접 설치한 Engine / Docker Desktop 등), 이미지와 명령어를 기록하고, 설명에서 호스트가 어느 환경을 가리키는지 분명히 합니다.

## 추가 탐구

프로세스와 격리 또는 이미지와 파일 저장 중 관심 있는 부분을 더 살펴볼 수 있습니다. 네트워크·보안·전체 내부 구현을 한 번에 끝낼 필요는 없습니다.

## 완료 기준

컨테이너를 실행·중지·삭제할 때 어떤 일이 일어날지 예상하고, 직접 확인한 결과를 설명할 수 있습니다. 아직 확인하지 못한 설명과 추가 질문은 구분해 남깁니다.
